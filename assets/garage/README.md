# Personal garage assets

The catalog lists the owner's local models. GLBs are deliberately ignored by git;
copy personally licensed files into this directory using the catalog filenames.
Missing files are skipped. On first launch the available cars are copied into the
Accord OS application configuration directory, with the first available entry
selected. An existing garage is never reseeded. Use **Add car** for later imports.

The local Accord export derives from the owner-supplied Assetto Corsa CB7 model
by Lucas Macedo and Caleb Short. No standalone redistribution grant is recorded;
do not publish that GLB. Original model terms and credits for the Civics and
4Runner are retained in `SOURCE-CREDITS.md`. These assets are not covered by the
application's GPL licence. This project is independent of Honda and Toyota.

The local Accord export restores the original GLB's double-sided paint materials.
The stock exporter dropped that flag, making the rear door skins disappear in Qt.
Geometry and original source models are unchanged; the pre-repair local copy is
kept as a `.bak` file. The same material flags apply to the imported personal copy.
